## Resumo Rapido
- Sistema de gestao de ordens de servico para higienizacao de cabines sanitarias
- Plataforma: Bubble.io | Dominio: operation.app.br
- Cliente: Brasil Terminal Portuario S/A (Porto de Santos)
- 19 cabines cadastradas via QR Code
- 3 telas: Aplicativo (mobile), Painel de Controle (admin), QR Code (cadastro)
